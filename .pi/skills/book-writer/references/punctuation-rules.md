# 中文写作标点六项体检 — 全角 vs ASCII 守门员

适用域：任何中文长文输出（书籍、章节、序言、整合书稿），写入路径必经此关。

基于实战教训提炼（2026-08-06 写长书踩坑记录）。

## 六项标点规则对照表

| # | 标点类型 | 必须用（全角） | 禁止用（ASCII） | Unicode |
|---|---------|--------------|---------------|---------|
| 1 | 中文双引号 | “” | " | U+201C / U+201D |
| 2 | 句号 | 。 | . | U+3002 |
| 3 | 顿号（并列项） | 、 | ,（中文并列场景） | U+3001 |
| 4 | 书名号 | 《》 | <> | U+300A / U+300B |
| 5 | 括号 | （） | () | U+FF08 / U+FF09 |
| 6 | 破折号 | ——（两个 em dash） | --（两个 hyphen） | U+2014 × 2 |

## 何时跳过检查

以下场景本规则自动豁免，不计入违规：

1. **代码块内部**：被三个反引号 ``` ``` ``` 包围的代码块
2. **URL、邮箱、文件路径**：保留 ASCII 标点
3. **数学公式**：保留 ASCII 运算符
4. **英文专有名词内部**：保留 ASCII 标点

## 修复策略（自动化）

### 双引号（最易出错）
按段（空行分隔）独立配对：
- 一段内 ASCII `"` 出现奇数次 → 第一个替换为 `“`，其余替换为 `”`
- 一段内 ASCII `"` 出现偶数次 → 全部替换为 `“` 和 `”` 交替
- 全段不匹配（奇数次且不到成对）则报警，不自动改

### 其他 ASCII 标点
- `.` → `。`（仅在中文句子末尾，前一个字符不是 ASCII）
- `,` → `、`（仅出现在列举/并列场景，需人工判断或暂不改）
- `<...>` → `《...》`
- `(...)` → `（...）`
- `--` → `——`

## 触发时机

- 单章节写完 → 跑一次
- 整合后整本书 → 跑一次
- 推送/上传前 → 跑一次

## 输出报告格式

每次体检输出：

```
=== 中文标点体检报告 ===
文件: 
六项总分: /6
[1/6] 双引号 "": ✅/❌ (左=数, 右=数)
[2/6] 句号 ASCII '.': ✅/❌ (违规 N 处)
[3/6] 顿号 ASCII ',': ✅/❌ (违规 N 处)
[4/6] 书名号 ASCII '<>': ✅/❌
[5/6] 括号 ASCII '()': ✅/❌
[6/6] 破折号 ASCII '--': ✅/❌

违规示例:
  L123:他说"你好" → "你好"应为 "..."

总判定: ✅ 通过 / ❌ 未通过（需修复 N 项）
```

## 防御三件套（写在 BRIEF.md 顶部）

```
1. 写作前 BRIEF 写明"中文用全角标点"
2. 写完跑 punctuation_check.py
3. 推送/上传前再跑一次
```

这是 subagent 并行写作时避免各章标点不一致的最有效工具。
